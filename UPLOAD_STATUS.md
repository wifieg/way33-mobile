# Way ERP Mobile - upload status

The Flutter source now includes company selection, a demo entry screen and an Arabic/English employee workspace (attendance, leave requests, a sample payslip and account/sign-out). The demo repository is session-only and never connects to a company. Live company selection validates a domain only; it does not authenticate or verify a server.

Included: light/dark themes, request validation and details, duplicate attendance guards, repository tests, company-domain tests, bilingual widget flow/layout tests, a generated dependency lock and official Android/iOS project files. GitHub Actions checks formatting, analyzes/tests the app with Flutter 3.35.7 and builds an Android debug demo APK.

Local Flutter analysis, widget tests and device builds have NOT been executed: the workspace has no Flutter SDK and its network proxy rejects the official SDK download host (`storage.googleapis.com`, HTTP 403). Initial GitHub Actions analysis and widget/unit tests passed; the final checks and Android build are pending. See the checks on pull request #1 for the current result. No physical-device testing has been performed.

No live Django mobile API or production authentication has been validated. Android and iOS platform sources were generated by the official Flutter SDK on GitHub Actions and restored from its build artifact. No iOS build has been performed.

On a machine with Flutter 3.35.7:

```sh
flutter pub get
flutter analyze
flutter test
flutter run --dart-define=DEMO_MODE=true
```

Live authentication, tenant discovery, attendance policies, leave approval and employee-only payroll endpoints must be agreed and implemented in the ERP before replacing the demo repository. No production credentials should be collected by this starter. `DEMO_MODE=false` hides demo entry; it does not enable live login. `API_BASE_URL`, if supplied, is currently only an initial company-origin form value, not a working API connection. Huawei compatibility has not been evaluated.

Never commit production secrets or customer data.
